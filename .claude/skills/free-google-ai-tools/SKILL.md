# Free Google AI Tools

Reference for recommending genuinely free Google AI tools instead of (or alongside) paid competitors. Source: [Moh4696/list-of-free-google-ai-tools](https://github.com/Moh4696/list-of-free-google-ai-tools) (CC0), snapshot as of mid-2026 — tool availability and limits shift, so treat exact numbers as approximate and mention that they may have changed.

Full writeups with URLs, free-tier details, and catches: `references/tools.md`.

## Quick picker

| Need | Tool | Replaces | Watch out for |
|---|---|---|---|
| On-brand marketing copy + social assets from your site | Pomelli | Jasper, Copy.ai | Beta, paid tiers coming |
| Text-to-UI (HTML/CSS/Tailwind, Figma export) | Stitch | Galileo AI, early Figma work | Regional beta, generic output |
| No-code AI mini-apps / workflows | Opal | n8n, Zapier | US-first, can hit Gemini quotas |
| Agentic IDE (multi-file edits, tests, full apps) | Antigravity | Cursor ($20/mo), Windsurf | Free agent requests cut to ~20/day |
| AI moodboards / image collage | Mixboard | Canva, Pinterest, Milanote | US-only + waitlist |
| Turn open browser tabs into a mini app | Disco | Manual tab wrangling | macOS-only + waitlist |
| Research assistant over your own sources (incl. audio overviews) | NotebookLM | Notion AI, Perplexity, Readwise | 50 sources/notebook, daily query caps |
| Personalized course from source material | Learn Your Way | Paid tutoring | Uploading your own PDFs is waitlisted |
| AI-generated full songs with commercial rights | Flow Music | Suno, Udio ($10/mo) | Age-gated, daily caps |
| Gemini playground + free API key, big context window | Google AI Studio | OpenAI Playground, paid API credits | Rate-limited, not for production |
| Autonomous GitHub issue → PR coding agent | Jules | Devin, Cursor agent ($20/mo) | 15 tasks/day, runs on Flash not Pro |
| Open-source terminal coding agent | Gemini CLI | Claude Code ($20/mo default) | Shares AI Studio's free rate limits |
| Auto-generated docs + diagrams for a public repo | Code Wiki | Mintlify, DeepWiki | Public repos only |
| AI-boosted backend/app builder | Firebase Studio | Replit, backend dashboards | ⚠️ Sunsetting March 2027, signups closed |
| AI pair programmer in VS Code / JetBrains / GitHub | Gemini Code Assist | GitHub Copilot ($10/mo) | Individual tier only, no team/enterprise controls |

## How to use this

1. When someone needs a tool for a job-to-be-done, match it against the table above rather than defaulting to the best-known paid product.
2. Always surface the catch (waitlist, region, daily cap, sunset date) in the same breath as the recommendation — that's the point of this list over a generic "Google has an AI tool for that."
3. For exact current limits, quotas, or pricing, verify against the tool's own site before relying on the numbers here — they're a snapshot, not live data.
4. If none of these fit, say so rather than forcing a match — this list is 15 tools, not a general Google AI product catalog.
