# Delivery order

Deliver in the user's language. Keep the DNA analysis short, because the remixes are the product.

1. **DNA card**, filled from `dna-card.md`. Lead with the load-bearing genes in 3-4 lines, then the full card.

2. **Three ranked remixes.** For each one:

   ```
   ### Remix <rank>: <Close | Shifted | Crossbred>, score <x>/20
   Hook <x>/5 · Voice fit <x>/5 · Proof <x>/5 · Why now <x>/5

   <post text, ready to paste, in the platform's line format>

   Format: <text only | single image | carousel N slides | short video>
   Visual brief: <layout, text on image, colours in the user's brand, face or not, type>
   Image prompt: <ready-to-paste prompt, brand colours as hex, aspect ratio, no text or the exact short text>
   Carousel slides (if any): 1. <cover> 2. ... N. <CTA>
   First comment: <link, resource or follow-up question>
   Fingerprint match: <structure_match>/100 · Originality: PASS (overlap <x>, longest run <n>)
   ```

3. **Originality report.** The script results for all three remixes and the five manual checks, each marked pass or fail, with a one-line note on anything that was rewritten.

4. **Posting note.** The suggested day and time window for the audience, whether to put the link in a comment, and what to reply to in the first hour.

5. **After 48 hours.** Ask for impressions, reactions, comments, reposts and profile views. Note which genes seemed to work, and offer to add them to `content-dna/library.md`.
