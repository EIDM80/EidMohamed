# Arabic and bilingual remixes

## Choosing the language

- Match the audience, not the source. A viral English post can become an Arabic remix when the user's audience reads Arabic. The DNA transfers across languages. The wording must not.
- For a mixed Gulf or MENA professional audience on LinkedIn, the usual options are English only, Arabic only, or Arabic first with a short English summary. Avoid full duplication, which doubles the length and pushes the hook's second half below the fold.

## Register

- Use **Modern Standard Arabic (فصحى مبسطة)** for institutional and university accounts, formal announcements, and thought leadership.
- Use **Light Gulf or Egyptian dialect** for personal stories and humour on personal profiles, and only when it matches how the user actually writes. Don't switch register mid-post unless it's a deliberate device, such as a quoted line in dialect.
- Keep technical terms that the audience uses in English (SEO, AI, KPI) in English, and don't force translations nobody uses.

## Hooks that carry well into Arabic

- `before-after` with years and numbers: «٢٠١١: ... / ٢٠٢٦: ...».
- `confession`: «أعترف: ...».
- `direct-callout`: «إذا كنت تدير التسويق في ...».
- `contrarian`: «توقّف عن ...».
- `open-loop` built on a spoken line: «قال لي المدير جملة واحدة غيّرت ...».

Arabic hooks read better with fewer words than a literal English equivalent. Aim for the same **character** count in the hook, not the same word count. The fingerprint script reports both.

## Typography and layout

- Choose **Arabic-Indic digits (٠-٩)** or **Western digits (0-9)** and use one consistently in a post. On LinkedIn in the Gulf, Western digits are common and read well in mixed feeds.
- Punctuation: use the Arabic question mark ؟ and comma ، in Arabic text.
- Emoji and bullet arrows: remember right-to-left direction. Use ← rather than → for "next" in Arabic lists.
- For graphics, choose Arabic fonts with good weight range (for example IBM Plex Sans Arabic, Cairo, Tajawal, Noto Kufi Arabic). Don't set Arabic in a Latin-only font. Check that letters connect correctly in the final render.
- For mixed Arabic and English on one image, set a clear hierarchy (one language is the headline) to avoid direction clashes.

## Originality across languages

Translating the source post, even loosely, is copying. The script's overlap check cannot see across languages, so check by hand: back-translate your Arabic remix in your head. If it reads like the original's sentences in order, rewrite it with the user's own story.
