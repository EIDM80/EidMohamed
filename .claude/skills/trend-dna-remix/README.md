# trend-dna-remix

تحلّل منشوراً ناجحاً أو رائجاً (لينكدإن، X، إنستغرام، تيك توك...) وتستخرج **الـDNA** الخاص به: نوع الخطّاف، الهيكل، الإيقاع، القوس العاطفي، الـCTA، واللغة البصرية. ثم تعيد بناء **3 منشورات جديدة** بمحتواك وقصتك وصوتك، مع توجيه للتصميم وبرومبت صورة وفحص أصالة يثبت أن شيئاً لم يُنسخ.

## كيف تستخدمها

اكتب في Claude Code مثلاً:

- «حلّل هذا المنشور واعمل لي منشوراً بنفس الـDNA عن تجربتي في التسويق الجامعي» ثم الصق نص المنشور وأرقامه.
- «ليه المنشور ده انتشر؟ استخرج الـDNA بتاعه.»
- «حوّل هذا الريل من تيك توك إلى كاروسيل لينكدإن بنفس الأسلوب.»

## ما الذي تحتاجه منك

1. نص المنشور المصدر (أو لقطة شاشة)، وأرقام التفاعل إن وُجدت.
2. **قصتك أو معلومتك الحقيقية** التي سيحملها المنشور الجديد. المهارة لا تخترع قصصاً ولا أرقاماً أبداً.
3. المنصة واللغة (عربي، إنجليزي، أو الاثنان) وألوان هويتك إن أردت تصميماً.

## ما الذي تحصل عليه

- **بطاقة DNA**: القياسات الرقمية مع الجينات الحاملة للنجاح.
- **3 نسخ مرتّبة**: قريبة، ومُزاحة (صيغة مختلفة)، ومهجّنة (مع أسلوبك الخاص).
- لكل نسخة: النص الجاهز، ووصف التصميم، وبرومبت الصورة، وشرائح الكاروسيل، والتعليق الأول.
- **تقرير الأصالة**.

## السكربت

```bash
# بصمة منشور واحد
python3 .claude/skills/trend-dna-remix/scripts/post_dna.py source.txt

# مقارنة النسخة الجديدة بالأصل + فحص الأصالة (يخرج بالكود 2 إذا كان هناك نسخ)
python3 .claude/skills/trend-dna-remix/scripts/post_dna.py source.txt --compare remix.txt
```

يدعم العربية والإنجليزية والنص المختلط، ولا يحتاج أي مكتبات خارجية.
