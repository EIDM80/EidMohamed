# تعريفات سير العمل

صدّر كل تطبيق Dify من واجهته (`⋯` ← Export DSL) واحفظ الملف هنا مع كل إصدار.

## لماذا في Git

منطق سير العمل يعيش داخل قاعدة بيانات Dify، لا في مستودعك — فلا مراجعة كود، ولا تاريخ تغييرات،
ولا استرجاع سريع عند خطأ. تصدير الـ DSL إلى هنا يعيد هذه الثلاثة.

## الحارس

`make check-workflows` يرفض أي ملف هنا لا يطبّق عزل المستأجرين. يفحص أربع حالات:

| الخطأ | لماذا خطير |
|---|---|
| `metadata_filtering_mode: disabled` | كل مستأجر يسترجع مستندات الجميع |
| ترشيح على حقل آخر | العزل غير مطبّق أصلاً |
| قيمة ثابتة بدل `{{#sys.user_id#}}` | تعمل في الاختبار وتتسرّب في الإنتاج — أسوأ نمط فشل |
| `contains` بدل `is` | يطابق معرّفات مستأجرين آخرين تشترك في بادئة |

اجعله خطوة إلزامية في خط النشر. الملف `example-support-chat.yml` نموذج صحيح للمقارنة.
