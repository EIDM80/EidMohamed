# Mark LI — تثبيت وتقييم

المستودع: <https://github.com/FatihMakes/Mark-LI> — مساعد صوتي يتحكّم في الحاسوب،
يراقب العتاد، ويؤدّي مهام آلية. فحصتُ الشيفرة بتاريخ 2026-08-26 قبل كتابة هذا الدليل.

## ما هو فعلياً

مشروع Python حقيقي وضخم (`main.py` وحده 80 ألف حرف، و`ui.py` 141 ألفاً) بواجهة PyQt6،
و22 وحدة أفعال، ونظام إضافات، ولوحة تحكّم من الهاتف.

القدرات كما وجدتُها في الشيفرة لا في الوصف فقط:

| الوحدة | ما تفعله |
|---|---|
| `system_monitor.py` | مراقبة المعالج والذاكرة وكرت الشاشة والحرارة، مع تنبيهات صوتية |
| `background_monitor.py` | مراقبة مواضيع تحدّدها أنت، وفحص يومي للأخبار |
| `computer_control.py` | اختصارات لوحة المفاتيح، الفأرة، إدارة النوافذ |
| `computer_settings.py` | الصوت، السطوع، الواي فاي، الطاقة |
| `proactive.py` | مبادرات واعية بالوقت والسياق |
| `file_controller.py` / `file_processor.py` | عمليات الملفات، وقراءة المستندات وتلخيصها |
| `dev_agent.py` / `code_helper.py` | مهام برمجية ومراجعة كود |
| `reminder.py` | تذكيرات عبر Task Scheduler في ويندوز |
| `dashboard/server.py` | لوحة تحكّم من الهاتف عبر QR |

## ثلاث حقائق يجب أن تعرفها قبل التثبيت

### 1. لا يعمل على كرت الشاشة عندك — بل على سحابة Google

هذه أهم نقطة، وقد أخطأتُ فيها أول الأمر. المحرّك هو **Gemini Live API**:

```
main.py:85   LIVE_MODEL = "models/gemini-2.5-flash-native-audio-preview-12-2025"
main.py:93   json.load(f)["gemini_api_key"]
```

يوجد ملف `core/llm_client.py` يدعم Ollama ويذكره كـ«المزوّد الافتراضي» — لكن **لا ملف
واحد في المشروع يستورده**. تحققتُ: صفر مستوردين. فهو شيفرة غير موصولة، ربما تمهيد لنسخة
قادمة.

**النتيجة العملية:** الـRTX 4080 لا دور له هنا. Mark LI يحتاج مايكروفوناً ومفتاح Gemini
مجاني وإنترنت. أما منظومة Ollama التي أعددناها فتبقى مشروعاً منفصلاً مفيداً — لكنها ليست
محرّك هذا البرنامج.

### 2. الترخيص يمنع الاستخدام التجاري

الترخيص **CC BY-NC 4.0** — «للاستخدام الشخصي وغير التجاري فقط».

- استخدامه في بيتك لشؤونك الخاصة: **مسموح**.
- استخدامه في عملك بجامعة USTF، أو لأي غرض تجاري: **مخالف للترخيص**.

هذه ليست تفصيلاً قانونياً هامشياً بالنسبة لك تحديداً، لأن أغلب ما ناقشناه (تحليلات
التسويق، البريد، الحملات) هو عمل مؤسسي. إن أردت هذه القدرات للعمل، فالمسار الآخر
(Claude + الموصّلات) لا يحمل هذا القيد.

### 3. سطح ثقة واسع

البرنامج يتحكّم بلوحة المفاتيح والفأرة والملفات، ويسجّل نفسه في بدء التشغيل، ويفتح خادماً
على الشبكة. فحصتُ كل النطاقات الخارجية في الشيفرة فوجدتها متوقّعة كلها (Google وYouTube
وDuckDuckGo وSteam وElevenLabs) — **لا شيء مريب**. لكن ابقَ على علم:

**لوحة الهاتف تستمع على `0.0.0.0`** (السطران 850 و877 في `dashboard/server.py`) — أي على
كل الشبكة لا على جهازك فقط، ومفتاح الاقتران **6 رموز** (حروف كبيرة وأرقام) مع تشفير
AES-256. مقبول على شبكة منزلية موثوقة؛ لا تفعّله على شبكة عامة أو شبكة الجامعة، ولا تفتح
له منفذاً في الراوتر.

## المتطلبات

| المتطلب | التفصيل |
|---|---|
| نظام | ويندوز 10/11 (يعمل أيضاً على macOS وLinux) |
| Python | **3.11 أو 3.12** — لا 3.13 |
| مايكروفون | ضروري |
| مفتاح API | مفتاح Gemini مجاني من [Google AI Studio](https://aistudio.google.com/apikey) |
| كرت الشاشة | غير مطلوب |

> ⚠️ يحذّر المطوّر نفسه أن `requirements.txt` ناقص عمداً. توقّع أخطاء
> `ModuleNotFoundError` وثبّت الناقص يدوياً. هذا متوقّع لا خلل.

## التثبيت — الطريقة السهلة

بما أن Claude Code يعمل على جهازك، لا تثبّت بنفسك. افتح PowerShell (**عادي، بلا صلاحيات
مسؤول هذه المرة**)، اكتب `claude`، ثم الصق:

```
ثبّت مشروع Mark LI على هذا الجهاز: https://github.com/FatihMakes/Mark-LI

الخطوات:
1. تحقّق أولاً من نسخة Python. المشروع يحتاج 3.11 أو 3.12 تحديداً.
   إن كانت 3.13 أو أحدث، ثبّت 3.12 عبر winget وأنشئ به بيئة افتراضية.
2. استنسخ المستودع في مجلد مناسب.
3. أنشئ بيئة افتراضية venv وفعّلها — لا تثبّت الحزم على Python العام.
4. pip install -r requirements.txt
5. python -m playwright install
6. python main.py

تنبيهات:
- المطوّر يذكر أن requirements.txt ناقص عمداً. إن ظهر ModuleNotFoundError
  فثبّت الحزمة الناقصة واستمر. هذا متوقّع.
- سيطلب البرنامج مفتاح Gemini API عند أول تشغيل. سأدخله أنا يدوياً في الواجهة.
- المشروع يتحكّم بلوحة المفاتيح والفأرة والملفات. اشرح لي ما يفعله كل أمر
  قبل تنفيذه.

جهازي: ويندوز 11، 64 جيجابايت رام. اشرح كل خطوة بالعربية.
```

قبل ذلك، احصل على مفتاح Gemini المجاني من
[aistudio.google.com/apikey](https://aistudio.google.com/apikey) — سجّل دخولاً بحساب
Google، اضغط «Create API key»، وانسخه. ستلصقه في واجهة البرنامج عند أول تشغيل.

## التثبيت اليدوي

```powershell
git clone https://github.com/FatihMakes/Mark-LI.git
cd Mark-LI
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m playwright install
python main.py
```

استخدام `venv` مهم: المشروع يثبّت 27 حزمة منها `pyautogui` و`pywin32`، ولا تريد خلطها
بحزم Python الأخرى على جهازك.

## علاقته بما بنيناه سابقاً

| | Mark LI | منظومة Ollama المحلية | دليل Claude 2.0 |
|---|---|---|---|
| المحرّك | Gemini سحابي | نماذج على كرتك | Claude + موصّلات |
| كرت الشاشة | لا يُستخدم | 16 ج.ب مستغلّة | لا يُستخدم |
| التكلفة | مفتاح مجاني (بحدود) | كهرباء فقط | ~20$ شهرياً |
| يتحكّم بالحاسوب | **نعم، بعمق** | جزئياً عبر Computer | عبر المتصفح فقط |
| الاستخدام التجاري | **ممنوع** | مسموح | مسموح |

الثلاثة لا تتعارض. Mark LI هو الوحيد الذي يعطيك التحكّم العميق في الجهاز والمراقبة —
وهو ما طلبتَه — لكن للاستخدام الشخصي وحده.
